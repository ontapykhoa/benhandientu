Cấu hình Proxy chia sẻ công khai hoặc API Key cá nhân

URL Proxy đã được gắn cố định trong biến GAS_PROXY_URL của file HTML. Mọi người truy cập web đều tự động sử dụng Proxy này.

Sau khi bấm Kiểm tra kết nối thành công, hãy copy URL này dán vào dòng const GAS_PROXY_URL = "..." ở đầu file HTML trước khi đẩy lên GitHub Pages.

Lưu ý bảo mật: Chế độ này chỉ lưu API Key trong bộ nhớ trình duyệt hiện tại (localStorage) để bạn tự luyện tập. Tuyệt đối không dán trực tiếp API Key vào file HTML đẩy lên GitHub công khai.
